Patch vs Replace vs Mutate:
- Full replace per slot dominant: Airflow XCom, Dagster output, n8n items, GitHub Actions
- Direct mutate: Flexget (entry dict)

- JSON Merge Patch (RFC 7396): recursive dict merge — single-process trusted plugin'ler için doğal seçim

HTTP transport for plugin SDK:
- Temporal/Cadence: gRPC çünkü worker'lar farklı process/dil
- GitHub Actions: action↔runner file pipe (subprocess izolasyon)

✅ Doğru olanlar:

Final Paradigma (kesinleşmiş)

Tek izin verilen "global"

- services.jobid (string) — orchestrator inject eder, plugin invoke'unda dolu
- Jinja: {{ jobid }} — render context'te dolu
- Interpolator: ${jobid} — runtime-deferred, render-time resolve
- Per_run plugin'lerde: jobid = None (job context yok, dürüst değer)

Kalkanlar (sıfır magic)

- services.current_job_id → SİL (eğer biri ID istiyorsa: services.jobid)
- services.current_plugin_name → SİL (plugin: self.manifest.name)
- services.run_id → SİL (plugin: read_state()["id"])
- services.mode → SİL (plugin: self.manifest.run_mode)
- <jobindex> sentinel → SİL (data_priority'de yok)
- data.run.X scope segment → SİL (manifest auto-route)

State shape (tek JSON)

{
  "id": run_id,
  "config": {...},
  "plugins": {scanner: {...}},        # per_run slot
  "jobs": {                            # DICT (S39 paradigması korunur)
    "job_xxx_0": {"id": ..., "index": 0, "input": {...}, "plugins": {...}},
    "job_xxx_1": {...}
  },
  "data": {                            # priority resolver envelope
    "scanner": {...},                  # per_run kategoriler
    "show": {0: {...}, 1: {...}},      # per_job kategoriler, jobindex key
    "movie": {...}
  }
}

data_priority shape (sentinel-free)

data_priority:
  show: [tmdb, omdb, tvmaze, tvdb]
  movie: [tmdb, omdb, tvdb]
  show.episode_title: [tmdb]
  scanner: [scanner]
Sistem manifest'ten run_mode okur → per_run plugin → run-level slot, per_job plugin → her job için ayrı.
